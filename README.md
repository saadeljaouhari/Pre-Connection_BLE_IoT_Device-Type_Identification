# Pre-Connection_BLE_IoT_Device-Type_Identification
Toward Lightweight Pre-Connection BLE IoT Device-Type Identification

The growing diversity of IoT devices creates a need for gateways to identify device types before selecting discovery procedures and security policies. Bluetooth Low Energy (BLE) advertising offers an opportunity to identify a device's category before connection, without interrogating its connected services. Existing broadcast-based identification methods demonstrate high classification accuracy, but reported accuracy alone does not establish which observations are necessary, how features contribute jointly, or whether complex models justify their computing resource costs. We present a pre-connection classification pipeline combining packet structure, service-related advertising information, and available channel/timing descriptors. It excludes explicit identity values and connected GATT/ATT observations. We examine feature dependencies and compare the performance of Random Forest, a Multi-Layer Perceptron (MLP), and a Decision Tree. On our 15,000 laboratory-associated and synthetic records with 104 original labels, removing packet headers, with explicit identifiers, preserves perfect saved-split scores. Validation-only selection reduces 19 numerical features to two, while a decision tree matches larger models with a 12.9~kB serialized model and lower measured inference cost. The study examines which features can be removed without reducing device-type recognition performance, how features contribute when combined, and whether a small decision tree can match larger models while requiring less storage and prediction time. These questions guide the design of a simpler classification pipeline for IoT gateways, within the limits of the evaluated data.
